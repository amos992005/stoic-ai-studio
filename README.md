# Stoic — Demo Reel

A code-first motion-graphics pipeline. One 15-second vertical reel, built
entirely from code and rendered on a CPU in GitHub Actions.

```
edge-tts  ──►  public/voiceover.mp3 ─┐
numpy     ──►  public/*.wav (SFX)    ├──►  Remotion (React/TS)  ──►  outputs/demo_reel.mp4
                                     │        1080x1920 · 30fps · 450 frames
```

No GPU. No Kaggle. No model weights. The render is a Node build plus a headless
Chrome rasterising CSS, which means it runs anywhere `ubuntu-latest` runs, in
about ten minutes, for free.

## The deliverable

`outputs/demo_reel.mp4` — 1080x1920, 30 fps, 450 frames (15.000 s), h264
`yuv420p` with AAC audio, vertical 9:16, phone-safe.

Four scenes, tiled with no gaps:

| Scene | Frames | Time | What happens |
|-------|--------|------|--------------|
| 1 · Hook | 0–104 | 0.0–3.5 s | Dark luxury gradient, perspective grid that scrolls and glows, kinetic type springing in word by word, `whoosh.wav` on the cut |
| 2 · Number | 105–224 | 3.5–7.5 s | Glassmorphism card rises, a big numeral counts up on a decelerating spring, four chart bars grow in sequence, `pop.wav` as the count lands |
| 3 · Callout | 225–344 | 7.5–11.5 s | Hard split screen: NOISE left, SIGNAL right with a specular sweep; three badges slide in on their own springs |
| 4 · Outro | 345–449 | 11.5–15.0 s | CTA slam-in, pulsing glow on a 24-frame beat with expanding rings, `riser.wav` underneath |

The voiceover spans the full timeline and eases out over the last 20 frames so
the reel never ends on a clipped word.

## Layout

```

  src/
    index.ts                registerRoot — the file CI names on the CLI
    Root.tsx                <Composition id="DemoReel"> 1080x1920 @30fps, 450f
    DemoReel.tsx            scene <Sequence>s, <Audio> cues, transitions
    theme.ts                timeline contract, palette, copy
    fonts.ts                vendored Anton + Inter, loaded via delayRender
    scenes/                 SceneHook · SceneMetric · SceneHighlight · SceneCta
    components/             Backdrop · Grid · GlassCard · GlowOrb
  public/
    fonts/                  Anton-Regular.ttf, Inter-Variable.ttf (committed)
    whoosh.wav pop.wav riser.wav   generated by scripts/generate_audio.py
    audio_manifest.json     what was generated, so CI can verify it

  generate_audio.py         edge-tts voiceover + procedural SFX
  check_reel.py             ffprobe gate for the audio and the rendered reel

  render-video.yml          the whole pipeline, CPU only

  demo_reel.mp4             the deliverable (committed by CI)

```

## Running it locally

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

bash scripts/render_setup.sh          # npm ci + browser + typecheck
python scripts/generate_audio.py      # needs outbound access for edge-tts
python scripts/check_reel.py --audio-only

cd remotion
npx remotion render src/index.ts DemoReel ../outputs/demo_reel.mp4 \
  --browser=chrome-headless-shell --codec=h264 --pixel-format=yuv420p
cd ..
python scripts/check_reel.py
```

`python scripts/generate_audio.py --sfx-only` builds the sound effects without
the voiceover, for working offline on visuals. CI always runs the full path: a
failed voiceover fails the job, because a silent reel should never ship.

## Why the checks exist

The render is the expensive part, so the cheap failure modes are caught first:

* **Before rendering** — `--audio-only` verifies the MP3 header, its duration
  (8.0–15.5 s), its loudness, and that each WAV is real RIFF/WAVE. A truncated
  edge-tts stream is rejected here in seconds.
* **After rendering** — `check_reel.py` measures the file with ffprobe: h264,
  `yuv420p`, 1080x1920, ~30 fps, ~450 frames, an AAC stream at least 13.5 s
  long, a duration within 0.35 s of 15.0, and a mean volume above −38 dB. It
  also looks at the audio stream's size and header, so a muxed-but-silent reel
  cannot pass.

Both gates are in the workflow, and the reel is only committed if they pass.

## Editing the reel

* **Timings and copy** live in `remotion/src/theme.ts`. The scene boundaries
  are a single source of truth; `check_reel.py` will catch a composition whose
  duration no longer matches 450 frames.
* **Script** lives in `scripts/generate_audio.py` (`VOICEOVER`). It is kept
  under ~300 characters so it fits the 15-second timeline at `+10%` rate.
* **Look** — palette in `theme.ts`, per-scene animation in `scenes/`.

Preview while editing with `cd remotion && npx remotion studio src/index.ts`.
